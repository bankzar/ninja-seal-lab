# NINJA LAB

เกม Battle ผ่านกล้อง สู้กับมาดาระด้วยหมัด ฟาดมือ หรือประสานอิน 3 ท่าตามลำดับแล้วปล่อยวิชา ภาพและการตรวจมือประมวลผลบนเครื่อง ไม่มี backend รับภาพ

## Battle — ฉากแรกกับมาดาระ

เปิดกล้องแล้วกด **เริ่มต่อสู้** ผู้เล่นเริ่ม HP 100 / MP 100 มาดาระ HP 360 แถบ HP/MP ติดขอบบนเมื่อเลื่อนหน้า MP ฟื้น 5 หน่วยทุกวินาทีที่กำลังสู้ สูงสุด 100 ใช้มือเดียวโจมตีธรรมดา ไม่เสีย MP:

- กำหมัดแล้วต่อยไปข้างหน้าหรือขยับหมัดอย่างรวดเร็ว: 8 ดาเมจ
- แบมือ ยกขึ้นแล้วฟาดลง: 11 ดาเมจ
- ผ่อนมือให้นิ่งก่อนทำครั้งถัดไป คูลดาวน์หมัด/ฟาด 0.65 วินาที

| วิชา | MP | ดาเมจ | เพิ่มเติม |
|---|---:|---:|---|
| เนตรวงแหวน + เพลิง | 35 | 64 | ดวงตาแดง + ไฟบนภาพผู้เล่น และไฟปะทะมาดาระ |
| แยกร่าง | 25 | 38 | ตัวจริง + 4 สแนปช็อต และลดดาเมจที่ได้รับครึ่งหนึ่ง 6 วินาที |
| พันปักษา | 30 | 58 | สายฟ้าตามมือ และสายฟ้าโจมตีมาดาระ |

วิชามีคูลดาวน์ร่วม 1.5 วินาที ถ้า MP ไม่พอ จะไม่ออกเอฟเฟกต์ ไม่เสีย MP และไม่ทำดาเมจ วิชาที่สำเร็จขัดจังหวะการโจมตีของมาดาระได้ ส่วนหมัดธรรมดาไม่ขัดจังหวะ มาดาระเตือนล่วงหน้า 1.3 วินาที โจมตีทุก 4.5 วินาที ดาเมจ 11 (17 ทุกครั้งที่สาม) เอฟเฟกต์ Battle ใช้เวลา 2.8 วินาที

HP ฝ่ายใดหมดจะตัดสินผลทันที ไม่โจมตีหรือฟื้น MP ต่อหลังจบ การพัก เปิดวิธีเล่น ฝึกท่ามือ ปิดกล้อง หรือออกจากหน้าต่างจะพัก Battle และไม่สะสมการฟื้น MP กด **สู้ต่อ** เพื่อเล่นต่อ กด **สู้ใหม่** หลังจบเพื่อคืนทรัพยากรและล้างคูลดาวน์

**ทดลอง Battle ไม่ใช้กล้อง** ใช้ปุ่มหรือคีย์ Z ต่อย / X ฟาด / 1–3 ใช้วิชา เป็นโหมดทดลองที่ระบุชัดเจน ใช้กฎ HP/MP และ AI ศัตรูเดียวกับการเล่นกล้อง ไม่ผ่านการตรวจอิน ภาพผู้เล่นในโหมดนี้เป็นหุ่นตัวอย่าง การจับมือจริงยังต้องทดสอบกับแสงและกล้องของผู้เล่น

## เสียง

เสียงวิชาเป็นไฟล์เสียงพูดภาษาญี่ปุ่นที่เตรียมไว้ในเกม: เพลิง “写輪眼！火遁！” (Sharingan! Katon!), แยกร่าง “影分身の術！” (Kage Bunshin no Jutsu!), และพันปักษา “千鳥！” (Chidori!) หมัดและตบใช้เสียงปะทะที่สังเคราะห์ขึ้นแยกกัน รวมทั้งเสียงหมัดของมาดาระเมื่อโดนผู้เล่น

เสียงทำงานหลังแตะ/คลิกเกมครั้งแรก มีปุ่ม **เสียงเปิด / ปิดเสียง** ด้านบนและจำค่าบนเครื่อง เสียงหยุดเมื่อพัก ปิดกล้อง หรือออกจากหน้าเกม ชื่อวิชาไม่พูดซ้อนกัน ไม่มีเสียงเมื่อ MP ไม่พอหรือยังติดคูลดาวน์ และไม่มีบริการสร้างเสียงหรือไมโครโฟนทำงานระหว่างเล่น

ไฟล์อยู่ใน `dist/assets/audio/` ใช้ Web Audio API โหลด/ถอดรหัสล่วงหน้า เสียงเรียกวิชาเตรียมด้วยเสียง `ja-JP-KeitaNeural` ผ่าน [edge-tts](https://github.com/rany2/edge-tts) (build-only) คำอ่านภาษาญี่ปุ่นกำหนดด้วยฮิรางานะเพื่อรักษาชื่อวิชา ดูข้อความและค่าเสียงใน `dist/assets/audio/manifest.json` สร้างไฟล์ใหม่ด้วย `generate_audio.py` โดยติดตั้ง `edge-tts==7.3.1` และ FFmpeg เฉพาะเครื่องที่เตรียมเสียง

## เปิดเล่นในเครื่อง

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ

```powershell
cd D:\naruto\ninja-seal-lab
node server.mjs
```

เปิด http://localhost:4173 แล้วอนุญาตกล้อง ควรใช้ Chrome หรือ Edge รุ่นปัจจุบัน เปิดผ่าน HTTPS หรือ localhost เท่านั้น การดับเบิลคลิก HTML ไม่รองรับกล้อง/โมเดล

## วิชาและอิน

| วิชา | ลำดับ | เอฟเฟกต์ |
|---|---|---|
| เนตรวงแหวน | ฉลู → ระกา → ชวด | ม่านตาแดง 3 ลูกน้ำตามตำแหน่งตา + เปลวไฟ |
| แยกร่าง | ระกา → ชวด → ฉลู | สแนปช็อตตัดฉากหลัง ซ้อนเพิ่ม 4 คน รวมตัวจริง 5 คน |
| พันปักษา | ชวด → ฉลู → ระกา | สายฟ้าเคลื่อนไหวตามมือ |

ลำดับทั้งสามเป็นลำดับย่อที่ออกแบบสำหรับเกม ไม่อ้างว่าเป็นลำดับวิชาตามต้นฉบับ ท่าฉลูกับระกาใช้รูปร่างแบบง่ายเพื่อรองรับเว็บแคม ดูภาพและคำแนะนำทางขวา

ค่าเริ่มต้นความคล้าย 35% ปรับได้ 30–85% เป็น heuristic similarity ไม่ใช่ความแม่นยำหรือความน่าจะเป็นที่ผ่านการวัด ระบบเลือกอินที่คล้ายที่สุดจากทั้งสามอิน โดยไม่รู้ว่ากำลังรออินไหน ต้องเห็นสองมือ ท่าชัดกว่าคู่แข่ง และค้าง 600ms ก่อนนับ มีเวลา 12 วินาทีระหว่างอิน การฝึกวิชานอก Battle และการดูตัวอย่างยังแสดงเอฟเฟกต์ 6 วินาที

หากนิ้วซ้อนกันแล้วตรวจยาก ให้แยกมือเล็กน้อยและกด “ฝึกท่านี้” ค้างท่า 3 วินาที ระบบเก็บเฉพาะค่าเฉลี่ยรูปทรงนิ้วใน localStorage ไม่เก็บภาพ ปุ่มดูตัวอย่างเอฟเฟกต์ไม่เพิ่มคะแนนและไม่ผ่านอิน ถ้ายังไม่เปิดกล้อง ตัวอย่างใช้หุ่นประกอบ

## เทคโนโลยี

Buildless HTML/CSS/ES modules; Canvas 2D; MediaPipe Tasks Vision `0.10.22-rc.20250304` ที่ pin และเก็บ WASM/โมเดลไว้ในเว็บ: HandLandmarker (2 มือ), FaceLandmarker (iris landmarks), ImageSegmenter (selfie foreground mask) ใช้ GPU และ fallback CPU ตามอุปกรณ์

โมเดลทำงานหลังผู้เล่นเปิดกล้องเท่านั้น UI วาดที่ display refresh rate การตรวจมือ/หน้าไม่เกิน 10Hz ทุกเอฟเฟกต์ใช้พิกัดภาพแบบกระจกเหมือนกัน ต้องให้หน้าหรือมือเห็นชัดเพื่อให้เอฟเฟกต์ตามตำแหน่งได้

`node --test tests/*.test.mjs` ตรวจลำดับอิน การค้างท่า การหมดเวลา ท่าเดิมไม่ถูกนับซ้ำ ทรัพยากร MP/HP การพัก/สู้ต่อ การโจมตีสวน แยกร่างป้องกัน คูลดาวน์ แพ้–ชนะ และท่ามือโจมตีจำลอง การทดสอบจำลองไม่รับรองความแม่นยำกับมือจริง แสง กล้อง หรือการบังนิ้ว จำเป็นต้องลองกับผู้เล่นจริง

`download-assets.mjs` ดาวน์โหลดแพ็กเกจและโมเดลจาก Google/GitHub/jsDelivr ใหม่ได้ ใช้ Apache 2.0 ตาม `dist/vendor/LICENSE.mediapipe` ฟอนต์ Google Fonts เป็นคำขอภายนอกที่ไม่ส่งภาพกล้อง
